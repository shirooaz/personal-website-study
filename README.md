## 🚀 快速开始

### 1. 下载项目

```bash
git clone https://github.com/shirooaz/personal-website-study.git
cd personal-website-study
```

### 2. 本地预览

直接用浏览器打开 `index.html`

或使用本地服务器：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```

访问 `http://localhost:8000`

### 3. 自定义修改

#### 修改 Logo Emoji

编辑 `script.js` 中的 `LOGO_EMOJIS` 数组：

```javascript
const LOGO_EMOJIS = [
    '🌿', '🍃', '🌸', '🌺', '🦋', '🐦', '📚', '🎋', 
    '✨', '🌱', '🪴', '🌾', '🍀', '🌴', '🎍'
];
```

#### 修改打字机文本

编辑 `script.js` 中的 `phrases` 数组：

```javascript
const phrases = [
    '记录成长的每一步 ✨',
    '分享技术与生活的点滴 💭',
    '二次元 · 生机 · 静谧 🌿',
    '欢迎来到我的世界 🏠',
];
```

#### 修改主题颜色

编辑 `style.css` 中的 `:root` 和 `[data-theme="light"]`：

```css
:root {
    --bg-primary: #0a1a14;
    --accent-primary: #f78c6c;
}
```

## 🌐 部署到 Cloudflare Pages

### 方式一：GitHub 集成（推荐）

1. 将项目推送到 GitHub 仓库
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
3. 进入 **Workers & Pages** → **创建应用程序**
4. 选择 **Pages** → **连接到 Git**
5. 选择你的仓库
6. 配置构建设置：
   - **构建命令**：留空
   - **输出目录**：`/` 或 `blog`
7. 点击 **部署**

### 方式二：直接上传

1. 进入 [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. **Workers & Pages** → **创建应用程序**
3. 选择 **Pages** → **上传静态资产**
4. 上传 `index.html`、`style.css`、`script.js` 等文件

### 自定义域名

1. 在 Pages 设置中选择 **自定义域**
2. 输入你的域名（如 `blog.153904.xyz`）
3. 按照提示配置 DNS
